🚀 DEPLOYMENT OPTIONS
────────────────────────────────────────────────────────────────────────────

OPTION 1: Deploy to Vercel (Recommended)
─────────────────────────────────────────────────────────────

Step 1: Create GitHub Repository
   1. Go to https://github.com/new
   2. Repository name: MCP-Experiments
   3. Click "Create repository"

Step 2: Push to GitHub (Windows)
   PowerShell:
   > .\deploy.ps1 YOUR_GITHUB_USERNAME

   Or manually:
   > git remote add origin https://github.com/YOUR_USERNAME/MCP-Experiments.git
   > git push -u origin master

Step 3: Deploy to Vercel
   1. Go to https://vercel.com
   2. Sign up/Login with GitHub
   3. Click "New Project"
   4. Import your MCP-Experiments repository
   5. Click "Deploy"
   6. Wait ~2 minutes
   7. Done! ✅

Your live URL: https://mcp-experiments-xxxx.vercel.app


OPTION 2: Deploy to Netlify
─────────────────────────────────────────────────────────────

Step 1: Push to GitHub (same as above)

Step 2: Deploy to Netlify
   1. Go to https://netlify.com
   2. Click "Add new site" → "Import existing project"
   3. Connect GitHub
   4. Select MCP-Experiments
   5. Click "Deploy site"


OPTION 3: Run Locally
─────────────────────────────────────────────────────────────

Simple HTTP Server:
   > python -m http.server 8000
   Visit: http://localhost:8000

With Live Reload (optional):
   > npm install -g live-server
   > live-server
